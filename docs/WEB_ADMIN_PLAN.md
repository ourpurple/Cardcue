| 项目 | 已确认内容 |

## 2. 目标闭环与非目标

目标闭环：

1. 管理员安全登录 Web。
2. 建立银行账户和卡片关系，配置邮箱及模型。
3. 保存配置后测试，测试通过再显式启用。
4. 定时或手动收件，保存邮件来源和任务结果。
5. 根据规则筛选账单候选，人工或经授权自动解析为草稿。
6. 对照邮件依据，人工选择账户、修正缺失或冲突字段、确认入账。
7. 查看按币种汇总的账单，记录还款、撤销错误记录。
8. Android 同步后台变化；手机关闭不影响后台工作。

首版不包含：真实支付或银行转账、网银登录、存储完整卡号/PIN/CVV、公开注册、多租户与复杂角色、SMTP 发信、POP3、自动把模型结果确认为欠款、扫描附件 OCR、破解加密 PDF、自动投资或财务建议。还款提醒与原有 R2 其他事项另行排期，不以“完整开发”为由扩展成这些功能。

## 3. 页面与交互

建议采用中文管理界面、桌面优先且适配手机浏览器；清晰展示状态、金额与操作后果。色彩与视觉稿在 W1 阶段核对，不先制作与真实接口脱节的演示页面。

| 页面 | 首版操作 | 必须呈现的异常与边界 |
|---|---|---|
| 登录 | 用户名、密码、登录与退出 | 错误信息不泄露账户是否存在；限流、会话过期提示 |
| 总览 | 分币种待还、近期到期、待审核、失败任务、最近成功收件 | 同步失败不是零欠款；共享账户账单不按卡片重复求和 |
| 账户与卡片 | 新建、查询、编辑、归档；卡片绑定账户 | 同尾号不等于同一张卡；归档保留历史，不删除欠款 |
| 邮件中心 | 按邮箱、时间、候选/解析状态筛选，分页，查看正文与附件元数据 | 正文未保留、附件不支持、提取失败、重复邮件与忽略状态 |
| 邮件详情 | 安全文本、解析记录、关联草稿；忽略/恢复、发起解析 | 不自动加载邮件图片、远程资源或执行 HTML；不修改远端邮箱 |
| 邮箱设置 | 多邮箱、连接参数、授权码、收件策略；保存/测试/启用/停用 | 密钥不回显；保存与启用分离；显示当前生效和待启用版本 |
| 模型设置 | 多配置、版本、参数、连接测试、样本测试、设为默认、撤销 | 调用可能收费；测试用合成内容；密钥不回显；不静默切换模型 |
| 草稿审核 | 字段与依据对照、账户/卡片选择、修改、确认、拒绝 | 缺失不猜测；冲突必须明确解决；重复点击或多端操作不重复入账 |
| 账单与还款 | 列表、详情、版本、来源、还款记录、部分/全额还款、撤销 | 明确“仅记录，不转账”；按实际剩余校验；更正不覆盖历史 |
| 任务中心 | 手动收件、补拉、解析、任务状态、取消、手动重试 | 已排队/执行中/成功/失败/取消/结果不确定；不无限重试 |
| 设备与安全 | 改密码、重新验证、一次性配对码、设备列表/撤销 | 配对码仅短时有效；撤销后不能继续同步或写入 |
| 系统状态与审计 | API、调度器、任务进程、积压、操作记录、版本信息 | API 存活不代表后台收件正常；日志不泄露正文、凭证或真实账单 |

共同要求：加载、空列表、失败、无权限状态明确；服务端分页；金额不以浮点数计算；写入期间防重复点击；危险操作有确认；并发冲突提示刷新，不用最后一次覆盖掩盖冲突。

## 4. 业务规则

### 4.1 账户、卡片与金额

- 账户、卡片、账单、来源、版本分别建模；稳定 ID 才是身份，尾号仅辅助显示与人工匹配。
- 同账户多卡共享账单只计一次。CNY/USD 分别汇总，首版不汇率折算；未知或其他币种不能默认当人民币入账。
- 所有金额以整数最小货币单位传输、保存、计算；页面使用精确字符串转换，拒绝多余小数、浮点输入、溢出和无效负值。
- 归档账户/卡片不物理删除关联账单、还款和审核历史；新增正式数据时检查对象状态与归属。
- 编辑携带预期版本，版本不一致返回冲突，不静默覆盖别处修改。

### 4.2 草稿审核与正式账单

- 邮件、附件和模型输出均是不可信输入。字段缺失保持未知，不填零、不推断年份或币种。
- 邮件解析只生成草稿；即使字段齐全，也需人工确认才能成为正式账单。
- 字段保留来源和原文片段；模型提供的依据必须能在提交的文本中找到。
- 仅有卡片尾号不自动决定账户。自动匹配只能给出无歧义建议，用户仍需确认。
- 重新解析生成新草稿/解析版本，保留旧审核结果与人工编辑；已确认账单不被重新解析覆盖。
- 同账户、币种、账期的重复或更正邮件进入明确关联流程；更正创建新版本，不重复累计欠款。
- 确认事务内锁定相关对象、核对草稿版本与账单当前版本、校验金额和日期、记录请求凭据及同步变更。
- 同一个请求重复提交返回原结果；相同请求 ID 但不同内容拒绝。

### 4.3 还款与撤销

- 还款记录只是记账，不表示银行执行了转账，也不根据邮件自动判定实际还清。
- 记录部分或全额还款时，事务内读取当前账单版本与有效已还总额，拒绝零值、负值及超额还款。
- 撤销保留原记录、时间和原因；重复撤销幂等，不删除原记录。
- 账单更正后的金额不得低于已有有效还款；并发更正、还款、撤销需遵守统一锁顺序。
- Web 与 Android 调用同一业务服务，同一事务写入同步变更记录。

## 5. 邮箱配置与收件

### 配置字段

邮箱名称、邮箱地址、登录用户名（默认邮箱地址）、IMAP 主机/端口、安全方式、授权码、文件夹、检查间隔、首次/补拉时间范围、每批数量、附件上限、发件人/主题筛选、是否保存非候选正文、是否自动解析。

建议默认：每 30 分钟检查，首次拉近 90 天，每批 100 封；非候选只保留必要元数据；自动解析默认关闭。提供新浪预设和通用表单，实际服务器参数在实现/真实连接时核验，不把未经验证的预设宣称可用。

### 配置生命周期

- 新建为停用；授权码仅首次填写或替换时传输，后台加密保存，查询只返回“已设置”。
- 修改为待启用配置，空白授权码表示保留，不覆盖为占位符字符串。
- 测试只进行连接、认证、文件夹可访问性等只读检查，不批量收件，不改变远端已读状态。
- 测试成功后管理员显式启用；失败不覆盖当前可工作的配置与凭证。
- 邮箱身份或游标命名空间变化需新建连接或经过显式迁移，不复用错误的 UID 游标。
- 停用阻止新任务；已有执行中任务的停止按安全检查点处理，已保存内容保留。

### 收件可靠性

- TLS/STARTTLS 必须校验证书，升级失败不能退回明文登录。
- 使用只读文件夹与不会设置已读标记的读取方式；不删除、不移动邮件。
- 基于邮箱、文件夹、UIDVALIDITY、UID 精确识别；Message-ID/内容指纹仅辅助处理重复，不错误合并不同邮件。
- 限制单封、附件、数量、连接耗时、文本提取页数/耗时；过大或不支持项目显示人工处理原因。
- 成功保存后推进检查点；单封失败不能悄悄跳过导致丢件；补拉不把正常游标倒退。
- 定时与手动请求共用持久化队列；进程重启后可恢复，重复提交同对象任务合并或明确拒绝。

## 6. 模型配置与调用

- 字段：配置名称、API Base URL、模型名、API Key、temperature、最大输出量、超时、限次重试、最大输入长度、JSON 模式、每日调用上限。
- 多配置和不可变配置版本；同一时刻一个默认版本；启用前通过测试；配置版本可撤销。
- 当前任务固定使用创建时选定的版本，默认配置变更不让执行中任务悄悄换供应商。
- 连接/格式测试使用合成输入，明确可能收费；真实邮件调用需明确授权，自动解析开关说明会发送哪些内容。
- 默认只发送必要文本，不发送邮箱授权码、模型密钥、无关附件或完整卡号；支持发送前脱敏及输入范围检查。
- 固定抽取任务，不授予模型执行工具、访问管理接口或修改账户的权限；邮件中的“指令”仅作为数据。
- 严格验证结构、金额、日期、币种及依据；超限不静默截断关键账单内容后装作成功。
- 按输入、提示词版本、配置版本形成缓存；重复解析可复用，有意识的强制重解析单独确认。
- 仅对明确可重试的限流/服务暂时异常有限重试。网络超时且供应商可能已处理时标记结果不确定，不无限自动补发。
- 记录配置版本、调用状态、耗时和供应商返回的用量。未知价格不伪造费用，未返回用量不填成实际为零。
- 未配置可用模型时明确“未配置/规则提取模式”，不悄悄调用旧环境变量中的其他服务。

## 7. 公网安全与隐私

### 登录、会话与权限

- 首版单管理员，无公开注册；通过服务器交互式命令创建/重置密码，不提交默认管理员口令。
- 建议密码不少于 14 字符，安全哈希存储；用户名与来源维度限流，错误响应保持一致。
- 使用服务端会话，Cookie 设为 HttpOnly、Secure、合适 SameSite；不在浏览器持久化管理员令牌。
- 建议会话最长 12 小时；凭证变更、配对码创建等敏感操作要求最近 10 分钟内重新验证密码。
- 写接口验证来源与 CSRF；修改密码使旧会话失效；退出释放当前会话。
- 设备凭证与 Web 管理权限分离；Android 不得读取邮箱授权码、模型密钥或管理配置。
- 设备配对改为管理员生成一次性短效码；建议 10 分钟有效、原子消费、失败限流；既有合法设备凭证不无故失效。
- 覆盖旧路由、批量接口、附件与新增路由的权限矩阵，禁止通过旧接口绕过测试启用、队列和额度规则。

### 内容与外连防护

- 邮件正文默认纯文本；确需 HTML 时严格净化并隔离，禁用脚本、远端资源与跟踪像素。
- 附件下载校验权限和路径，强制下载，不把存储路径暴露到 API；不执行附件。
- 自定义 IMAP/模型地址防止访问内网、回环与云元数据；检查 DNS 解析结果、重定向、地址重绑定和 TLS 主机名。
- 私有模型地址只能由部署侧明确放行，不能由普通表单绕过出站限制。
- 参数错误、异常堆栈和日志不得回显密码、授权码、密钥、原始邮件或真实账单；审计只记必要动作与对象标识。
- 密钥与数据库分离；已有密文迁移和轮换先验证解密兼容，不能直接换密钥使旧配置不可读。
- 原文与附件为受保护持久化内容；部署侧限制文件权限并规划加密备份。自动清理默认不启用，保留期限和清理预览确认后再执行。
- 公网前增加安全响应头、敏感接口禁缓存、代理请求体限制；生产接口文档关闭或受保护。

## 8. 目标技术与部署结构

技术方案（待本计划确认）：Web 采用 React + TypeScript + Vite + Ant Design；沿用 Python 3.11+、FastAPI、PostgreSQL、SQLAlchemy 和 Alembic。首版模块化单体，不为单人使用引入微服务、Redis 或复杂消息集群。

```text
浏览器 / Android
        │ HTTPS
现有反向代理（保留，不擅自替换）
        │
Web 静态服务 ── 同源 /v1 ── API
                              │
                   PostgreSQL 权威数据
                      ↑              ↑
                 独立调度器      独立任务进程
                                      │
                                IMAP / 模型服务
```

- Web、API、调度器、任务进程以 Docker 服务运行；数据库是否沿用现有实例，部署前核对，不默认重建。
- 入口使用同源代理，避免把密钥或调用逻辑放进前端。数据库、API 内部端口不直接公开。
- 宿主机反向代理场景建议仅映射 Web 到 127.0.0.1；代理本身在 Docker 内则使用约定网络。实际二选一由现有拓扑决定。
- 迁移作为显式单次操作，不在每个进程启动时争抢执行；非破坏性、兼容旧数据，先备份并在副本验证。
- 邮件内容卷、数据库和加密密钥分开管理；保持已有卷身份，禁止因 Compose 名称变化误建空卷。
- 提供不含凭证的环境变量模板、镜像构建、管理员初始化、健康检查、升级及恢复说明。
- 不向镜像、构建上下文或仓库带入本地 .env、真实邮件、账单样本、数据库备份和临时文件。
- 配置调度器/任务心跳、积压与失败状态；模型结果不确定任务不自动无条件重放。
- 上线前测试备份恢复。恢复数据库、正文和密钥需来自一致备份；恢复后同步世代处理明确。回滚不能默认用删表降级。

## 9. 接口、数据迁移与 Android 兼容

- 新增管理员、会话、登录限流、一次性配对码、模型配置/版本、运行设置、持久化任务、审计、调用统计、幂等请求记录。
- 现有账户、卡片、草稿补充并发版本字段；邮箱增加待启用配置、测试状态与调度检查点。
- 保留现有正式数据、同步协议与旧演示数据；不把旧演示欠款上传成正式账单。
- 列表接口统一分页/筛选/排序；详情显式选择安全字段，禁止直接序列化凭证或存储路径。
- 账户、账单、版本、还款的变更必须进入已有同步流；新增 Web 专属配置无需下发 Android。
- 旧未鉴权/直接模型调用/邮箱物理删除入口需盘点并迁移或封禁，不能只给新接口加锁。
- Android 仅做本次必要兼容：HTTPS 后台地址、一次性配对、队列化收件状态及错误提示；不顺便大改现有页面。
- 切换后台地址需隔离不同后台的缓存和令牌，不能把旧数据混入新服务；未经确认不清空缓存。
- 所有实际 Android 变更均独立执行构建、迁移和设备测试；后台通过不代表 APK 可用。

## 12. 必测用例矩阵

| 范围 | 最低覆盖 |
|---|---|
| 登录/权限 | 错误口令限流、未知用户一致响应、会话过期、退出、改密码失效、CSRF、设备越权、一次性码并发消费、旧入口绕过 |
| 凭证/外连 | 密钥不回显、表单空值保留、测试失败不切换、日志脱敏、内网与云元数据拒绝、DNS 重绑定、重定向、TLS 失败 |
| 收件 | 只读、断线恢复、授权失效、UIDVALIDITY 改变、重复邮件、大邮件、大附件、补拉、取消、进程重启、重复调度 |
| 模型 | 未配置、非 JSON、错误金额类型、缺失年份/币种、虚构依据、恶意邮件指令、输入超限、429/503、超时不确定、缓存、撤销版本 |
| 审核/金额 | 相同尾号不同账户、多卡共享账单、各币种分开、重复确认、过期版本、账单更正、并发还款、重复/超额还款、撤销历史 |
| 前端 | 登录失效、分页/筛选、加载/失败/空态、错误提示、表单保留秘密、危险操作确认、移动布局、精确金额转换、恶意正文 |
| 迁移/恢复 | 有历史数据的升级、密文可读、卷身份、备份恢复、重启任务状态、恢复后同步、不同后台缓存隔离 |
| 部署 | 仅预期入口可达、HTTPS Secure Cookie、代理来源设置、数据库不暴露、心跳与积压、重启后自动恢复、无默认密码 |

PostgreSQL 的行锁、唯一约束和事务并发必须在隔离 PostgreSQL 上验证，不能用 SQLite 或纯模拟测试代替。真实服务未提供时可完成模拟测试，但报告必须保留真实联调待办。
